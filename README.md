# BG Gayeb Koro ✨

**BG Gayeb Koro** is a high-performance, privacy-first AI background removal web application built with modern glassmorphism UI/UX. It runs machine learning segmentation locally inside your browser via WebAssembly, ensuring your photos never leave your device.

Creator: **Made with ❤️ by Alpha.HR**

---

## Features
- 🚀 **Real Browser AI**: Powered by `@imgly/background-removal` (ONNX WebAssembly runtime).
- 💎 **Premium Glassmorphism UI**: Frosted-glass floating navbar, glowing ambient orbs, and dynamic Light/Dark mode.
- 🎨 **Background Studio**: Replace backgrounds with transparent checkerboard, solid colors, gradient presets, or custom uploaded photos instantly.
- 🔍 **Interactive Studio**: Zoom controls, side-by-side preview comparisons, and image dimension indicators.
- 📥 **HD Multi-format Export**: Download crisp transparent PNGs, JPEGs, or WebPs with a single click.
